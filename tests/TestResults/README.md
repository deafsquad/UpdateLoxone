# Test Results and Coverage Reports

This folder contains test execution results and coverage analysis reports.

## Coverage Reports

### test-coverage-summary.md
- **Purpose**: Executive summary with key findings and recommendations
- **Use when**: You need a quick overview of coverage status and action items
- **Generated by**: Manual analysis after running enhanced coverage

### test-coverage-detailed.md  
- **Purpose**: Detailed function-by-function coverage with test descriptions
- **Use when**: You need to see exactly which tests cover each function
- **Generated by**: `Get-EnhancedTestCoverage.ps1 -GenerateReport -CheckUsage`

## Test Coverage Scripts

Run from the `/tests` directory:

```powershell
# Quick coverage check (console output only)
.\Get-QuickCoverage.ps1

# Basic coverage analysis with report
.\Get-TestCoverage.ps1 -GenerateReport

# Enhanced coverage with usage checking and detailed test descriptions
.\Get-EnhancedTestCoverage.ps1 -GenerateReport -CheckUsage -ShowDetails

# Find potentially unused functions
.\Find-DynamicFunctionCalls.ps1
```
